# Smart Event Management Platform

A full-stack event management platform designed to manage hackathons and other events through dedicated portals for **Organizers, Judges, and Participants**.

The platform provides role-based access, event management, participant registration, QR-based check-in, judging/evaluation workflows, and event dashboards through a unified system.

## 🚀 Live Demo

**Live Application:**  
https://smart-event-management-platform-beta.vercel.app

The application is deployed using:

- **Frontend:** Vercel
- **Backend:** Render
- **Database:** Neon PostgreSQL

> The live demo uses the production backend and database.

---

## 🎯 Problem

Managing an event such as a hackathon involves multiple disconnected processes:

- Participant registration
- Event management
- Check-in and attendance
- QR-based identification
- Team and project management
- Judge evaluation
- Role-based access
- Event-specific data
- Leaderboards and dashboards

The Smart Event Management Platform brings these workflows together into one system.
